# Parking API

This is a minimal ASP.NET Core Web API project located in the `api` folder. It is ready for REST endpoint development and can be extended or connected to a frontend later.

## How to run

1. Open a terminal in the `src` directory.
2. Run the following command:
   
   ```powershell
   dotnet run --project ./api
   ```

The API will be available at `http://localhost:5000` by default (or as shown in the terminal output).

## Project structure
- `api/` - ASP.NET Core Web API project

---

You can now add controllers, models, and other features as needed.
